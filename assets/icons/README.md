# 平台图标

本目录使用 [Simple Icons](https://simpleicons.org/) 的官方 SVG，供个人资料页的平台链接按钮使用。图标随站点托管，不依赖运行时 CDN。

- 上游仓库：[simple-icons/simple-icons](https://github.com/simple-icons/simple-icons)
- 固定提交：[`1bb2f6e6ea50f920de8d2f3d273ae48564a5eaee`](https://github.com/simple-icons/simple-icons/tree/1bb2f6e6ea50f920de8d2f3d273ae48564a5eaee)
- 上游 package 版本：16.37.0
- 图标许可：CC0 1.0 Universal，完整文本见 [LICENSE.simple-icons.md](./LICENSE.simple-icons.md)

四个文件均保留上游静态路径和 `viewBox="0 0 24 24"`，没有脚本、事件处理、外部链接或嵌入图片。可通过 CSS `mask-image` / `-webkit-mask-image` 配合 `background: currentColor` 使用，让按钮统一随主题配色；为按钮提供独立的可访问名称。

平台标识用于指引至相应平台，不代表平台为本站背书。真实个人账号地址由资料配置提供，图标不包含用户地址。
